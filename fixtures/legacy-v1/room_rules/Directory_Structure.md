```
Writing_Room/
├── .claude/
│   └── agents/             ← Subagent definitions
├── templates/
│   ├── world/              ← Markdown templates for all world bible elements
│   │   ├── character.md
│   │   ├── faction.md
│   │   ├── point_of_interest.md
│   │   ├── mythology.md
│   │   ├── hooks.md
│   │   └── world_description.md
│   └── story/              ← Markdown templates for story-level documents
│       ├── concept.md           ← Template for CONCEPT.md (filled by Story Ideator)
│       ├── outline.md           ← Template for OUTLINE.md (filled by Outliner)
│       ├── series_outline.md    ← Template for SERIES_OUTLINE.md (Book Series, filled by Outliner)
│       └── timeline.md          ← Template for Timeline.md (initialized by Story Ideator / Outliner)
├── worlds/                 ← One subdirectory per world bible
│   └── <World Name>/
│       ├── DESCRIPTION.md              ← World overview; entry point for all agents
│       ├── HOOKS.md                    ← Story hooks; browsed by Ideator, Planner, Writing Room Head
│       ├── SUMMARY.md                  ← World entity index; auto-maintained by Writing Assistant
│       ├── WORLD_ORDER.md              ← Story chronological order; maintained by Writing Assistant
│       ├── characters/                 ← One file per named character
│       ├── factions/                   ← One file per faction or organization
│       ├── mythology/                  ← One file per myth, legend, or prophecy
│       └── points_of_interest/         ← One file per named location
├── writing_concepts/       ← Reference material for story craft
│   ├── archetypes/
│   ├── story_structure/
│   ├── styles/
│   └── tropes/
└── stories/                ← One subdirectory per story or series
    ├── <Story Name>/                   ← Short Story / Novelette / Book
    │   ├── CONCEPT.md                  ← Story concept (Story Ideator)
    │   ├── OUTLINE.md                  ← Chapter outline (Outliner)
    │   ├── chapters/                   ← Finished chapters (Chapter_01.md, etc.)
    │   ├── current_chapter/
    │   │   ├── CHAPTER_PLAN.md         ← Plan generated by the Planner
    │   │   ├── CONTENT.md              ← Chapter being written
    │   │   └── current_reviews/        ← Output from reviewer agents
    │   └── state/
    │       ├── Timeline.md             ← Chronological event log
    │       └── bible/                  ← Story-local copy of the world bible
    └── <Series Name>/                  ← Book Series
        ├── CONCEPT.md                  ← Series-level concept (Story Ideator)
        ├── SERIES_OUTLINE.md           ← Series arc + book map (Outliner)
        ├── state/
        │   └── Timeline.md             ← Series-level event log
        └── Book 01 - <Title>/          ← Per-book directory (Outliner creates)
            ├── OUTLINE.md              ← Per-book chapter outline (Outliner)
            ├── chapters/
            ├── current_chapter/
            └── state/
                ├── Timeline.md         ← Per-book event log
                └── bible/
```
