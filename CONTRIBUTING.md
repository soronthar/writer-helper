# Contributing

Thanks for looking. A few things make changes easy to review:

- Read [AGENTS.md](AGENTS.md) (the rules in one page) and, if you are touching skills, [docs/WRITING_SKILLS.md](docs/WRITING_SKILLS.md).
- Run `python tools/lint_skills.py` and `python -m unittest discover -s tests` before sending a change. The same checks run in CI on Windows and Linux.
- The project layout ([docs/LAYOUT_V1.md](docs/LAYOUT_V1.md)) is frozen so existing projects keep working. Changes to it need a migration and are discussed first.
- Everything shipped here must be invented for this project: no real people, no text from published or private works. The sample world and stories are generated by `tools/build_sample.py`.
- Bug reports are most useful with the output of `wr_doctor.py`, the agent you used, and the folder you installed the skills into.
